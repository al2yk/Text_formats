<h1>Документация к программе FilesDDL</h1>
<p>Эта документация предоставляет обзор структуры, функциональности и использования программы FilesDDL. Программа предназначена для чтения и записи данных о курсах из/в файлы различных форматов, таких как CSV, JSON, XML и YAML.</p>
<h2>Обзор</h2>
<p>FilesDDL — это консольное приложение, которое позволяет пользователям выполнять следующие операции с данными о курсах:</p>
            <ul>
                <li>Чтение данных из файла</li>
                <li>Запись данных в файл</li>
                <li>Отображение данных</li>
                <li>Сортировка данных</li>
                <li>Поиск данных</li>
                <li>Добавление данных</li>
                <li>Удаление данных</li>
                <li>Изменение данных</li>
            </ul>
<h2>Структура программы</h2>
            <p>Программа состоит из двух основных классов: <code>Course</code> и <code>Files</code>.</p>

<h3>Класс <code>Course</code></h3>
            <p>Класс <code>Course</code> представляет собой структуру данных для хранения информации о курсе. Он включает следующие свойства:</p>
            <ul>
                <li><code>Id</code>: Уникальный идентификатор курса (целое число)</li>
                <li><code>Name</code>: Название курса (строка)</li>
                <li><code>Teacher</code>: Имя преподавателя (строка)</li>
                <li><code>CountStudent</code>: Количество студентов, посещающих курс (целое число)</li>
            </ul>
            <p>Класс также содержит метод <code>ToString()</code>, который возвращает строковое представление экземпляра класса.</p>

<h3>Класс <code>Files&lt;T&gt;</code></h3>
            <p>Класс <code>Files&lt;T&gt;</code> — это статический универсальный класс, содержащий методы для чтения и записи данных в файлы различных форматов. Он включает следующие методы:</p>
            <ul>
                <li><code>ReadFromFile(string file)</code>: Считывает данные из файла, формат которого определяется по расширению файла. Возвращает <code>List&lt;T&gt;</code> объектов или <code>null</code>, если файл не найден или произошла ошибка.</li>
                <li><code>WriteFile(List&lt;T&gt; items, string file)</code>: Записывает список элементов в файл в формате, определяемом по расширению файла.</li>
                <li><code>ReadCSV(string file)</code>: Закрытый метод для чтения данных из CSV-файла.</li>
                <li><code>ReadJSON(string file)</code>: Закрытый метод для чтения данных из JSON-файла.</li>
                <li><code>ReadXML(string file)</code>: Закрытый метод для чтения данных из XML-файла.</li>
                <li><code>ReadYAML(string file)</code>: Закрытый метод для чтения данных из YAML-файла.</li>
                <li><code>WriteCSV(List&lt;T&gt; items, string file)</code>: Закрытый метод для записи данных в CSV-файл.</li>
                <li><code>WriteJSON(List&lt;T&gt; items, string file)</code>: Закрытый метод для записи данных в JSON-файл.</li>
                <li><code>WriteXML(List&lt;T&gt; items, string file)</code>: Закрытый метод для записи данных в XML-файл.</li>
                <li><code>WriteYAML(List&lt;T&gt; items, string file)</code>: Закрытый метод для записи данных в YAML-файл.</li>
            </ul>
       

      
<h2>Функциональность</h2>
            <p>Основной класс программы <code>Program</code> предоставляет пользовательский интерфейс для выполнения различных операций с данными о курсах.</p>

<h3>Main</h3>
            <p>Метод <code>Main</code> служит точкой входа в программу. Он представляет пользователю меню параметров и соответствующим образом выполняет действия, основанные на выборе пользователя. Главный цикл продолжает работу, пока пользователь не решит выйти.</p>

 <h3>Чтение данных из файла (<code>ReadDataFromFile</code>)</h3>
            <p>Этот метод запрашивает у пользователя путь к файлу, а затем использует метод <code>Files&lt;Course&gt;.ReadFromFile</code> для чтения данных о курсах из файла. Если данные успешно прочитаны, они добавляются в общий список курсов.</p>

<h3>Запись данных в файл (<code>WriteFile</code>)</h3>
            <p>Этот метод запрашивает у пользователя путь к файлу и использует метод <code>Files&lt;Course&gt;.WriteFile</code> для записи данных о курсах в файл. Прежде чем записывать данные, программа проверяет, доступна ли какая-либо информация для записи.</p>

<h3>Просмотр (<code>View</code>)</h3>
            <p>Этот метод отображает данные о курсах, которые в настоящее время загружены в программу. Если нет данных для отображения, он отображает соответствующее сообщение.</p>

<h3>Сортировка (<code>Sort</code>)</h3>
            <p>Этот метод позволяет пользователю отсортировать данные курса по различным критериям, таким как идентификатор, название курса, преподаватель или количество студентов. Он спрашивает у пользователя критерии сортировки и использует метод <code>OrderBy</code> для сортировки данных.</p>

<h3>Поиск (<code>Search</code>)</h3>
            <p>Этот метод позволяет пользователю искать курсы по названию курса или имени преподавателя. Он запрашивает строку поиска и отображает результаты, соответствующие критериям поиска.</p>

<h3>Добавление (<code>Add</code>)</h3>
            <p>Этот метод позволяет пользователю добавить новый курс в список. Он запрашивает у пользователя сведения о курсе, такие как идентификатор, название, преподаватель и количество студентов, а затем добавляет новый курс в список.</p>

<h3>Удаление (<code>Delete</code>)</h3>
            <p>Этот метод позволяет пользователю удалить существующий курс из списка. Он запрашивает идентификатор курса, который необходимо удалить, и удаляет курс из списка.</p>

<h3>Изменение (<code>Modify</code>)</h3>
            <p>Этот метод позволяет пользователю изменить сведения об имеющемся курсе. Он запрашивает идентификатор курса, который необходимо изменить, а затем запрашивает у пользователя новые значения для названия курса, преподавателя и количества студентов.</p>
      
<h2>Использование</h2>
            <ol>
                <li>Запустите исполняемый файл программы.</li>
                <li>Программа отобразит меню параметров.</li>
                <li>Выберите параметр, введя соответствующую цифру.</li>
                <li>Следуйте инструкциям, отображаемым программой.</li>
            </ol>
      
<h2>Обработка ошибок</h2>
            <p>Программа включает обработку ошибок для обработки различных сценариев ошибок, таких как:</p>
            <ul>
                <li>Файл не найден</li>
                <li>Неверный формат файла</li>
                <li>Неверный формат входных данных</li>
                <li>Общие исключения, возникающие во время операций с файлами</li>
            </ul>
            <p>В случае возникновения ошибки программа отобразит сообщение об ошибке для пользователя.</p>
